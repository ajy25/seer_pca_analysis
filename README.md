# SEER PCa Analysis
This repository contains code to reproduce results for the paper "Survival Disparity Among Patients with De Novo Metastatic Prostate Cancer in the Androgen Receptor Pathway Inhibitor Era"

## Software
Python version: 3.12.12
Dependencies: `requirements.txt`

## Usage

Create a Conda environment, install the depdencies. Then run the `run_all.py` script, for example:

```bash
conda activate seer-pca
python scripts/run_all.py
```
